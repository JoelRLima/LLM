Baterias de testes

    
Prepare várias tarefas e acompanhe a execução automática. Os projetos e o armazenamento dos testes são separados da conversa. Fechar este painel mantém a bateria rodando. Para continuar após fechar o app, selecione a execução em processo independente abaixo. Após reiniciar o computador, a fila não recomeça sozinha; revise tarefas interrompidas antes de retomar.

    

    
Abrir uma fila pelo caminho

    
1. Preparar uma nova bateria
      

      
Cada subpasta deve conter task.md; seed/ guarda arquivos iniciais, checks.json ou verify.py definem a verificação. A importação cria uma cópia para este experimento. Verificadores Python executam código com os privilégios da sua conta, sem isolamento, e podem acessar outros arquivos e a rede. Importe somente tarefas confiáveis.

      
Criar uma tarefa simples sem editar arquivos
        
Escolha acima a pasta das tarefas. A tarefa será criada em uma subpasta nova; depois prepare uma bateria para importá-la. O critério é escrito por você e não é inferido da resposta do modelo.

        
        
        
        
        

        
        
        

      

      
      
Exemplo de organização
minhas-tarefas/
  01-tarefa/task.md
  01-tarefa/checks.json
  02-tarefa/task.md
  02-tarefa/seed/arquivo.py
  02-tarefa/verify.py

Plugins locais

    
Registre somente código de confiança. O protocolo stdio inicia programas locais e não fornece sandbox. O fingerprint identifica o manifest, não todo o código do plugin.

    
Habilitar, conceder permissões e autorizar na sessão são passos separados. Alterações administrativas limpam as autorizações temporárias. As alterações retornam o modo para somente leitura; ajuste o modo em Sessão → Modo de trabalho quando precisar executar processos. Aprovações continuam obrigatórias.
